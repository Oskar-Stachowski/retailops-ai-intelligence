`sha256:67f328b57c9cd9baf3491296cb35e9e5dba9beff84f73f059647b1ad70407d0f`.

rzeczywistych MLflow versions/promocji ani dopasowania modelu.

i 3 pointery**. Pierwszy output obejmuje 280 wartości; replay jednego produktu
nadpisuje tylko jego dni 1–7. Kolejny run kończy się niepowodzeniem. Następne
33 outputy dotyczą produktu spoza uprawnień podstawowego czytelnika.

HTTP i baza potwierdziły:

- 401 bez credentials i 403 dla `forecast:run` bez osobnego `forecast:read`;
- autoryzowany `total=14`, 422 dla scope spoza grantu, `200/no_data` dla innego
  scope i wspólne 404 dla niewidocznego przypiętego runu;
- rozłączne stabilne strony, wymaganie hasha kontynuacji, limity i zamknięte filtry dat;
- gotowość klasycznego odczytu bez MLflow i Bedrock;
- stare origin jako `stale`, bez zastępczych przedziałów;
- zachowanie dni 8–14 przy nowszym replay okna 7 oraz numeric release pins;
- 409 po zmianie widoku i dalszy odczyt oryginalnego niezmiennego runu;
- poprzednie wartości po nowszej nieudanej próbie, z powodem `newer_run_unpublished`;
- filtrowanie scope **przed** limitem 32 kandydatów: 33 obce outputy nie
  wpływają na czytelnika, pełny scope dostaje 429, przypięty run nadal jest dostępny;
